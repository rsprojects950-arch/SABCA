## RLS Design Pattern & Storage Buckets

Early migrations (`017_fix_login_bug.sql`) encountered infinite recursion when `profiles` policies queried `profiles` directly. Migrations **`018_safe_admin_visibility.sql`** and **`024_moderator_division_rls.sql`** resolved this by encapsulating role and division checks inside `SECURITY DEFINER` PostgreSQL helper functions (e.g., `public.is_admin()`).

### Supabase Storage Buckets

| Bucket Name | Consumer Modules | Deletion Cleanup |
| :--- | :--- | :--- |
| `avatars` | Member profile photos (`app/(tabs)/index.tsx`) | Purged by both `deleteAccount()` and `delete-user` Edge Function |
| `documents` | Personal member documents (`app/member/documents.tsx`) | Purged by `delete-user` Edge Function |
| `grievance-attachments` | Grievance PDF/image uploads (`app/services/grievances/`) | Purged by `delete-user` Edge Function |
| `events` | Event cover banners (`app/admin/create-event.tsx`, `app/(tabs)/events.tsx`) | Deleted via `deleteFileFromUrl()` when event is deleted |
| `news` | Association news imagery (`app/admin/create-news.tsx`, `app/(tabs)/events.tsx`) | Deleted via `deleteFileFromUrl()` when news item is deleted |
| `government_orders` | Official G.O. PDFs (`app/services/go-list.tsx`, `app/admin/create-go.tsx`) | Deleted via `deleteFileFromUrl()` on removal |
