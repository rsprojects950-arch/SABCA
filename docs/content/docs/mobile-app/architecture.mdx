# Mobile App Architecture (`sabca-app/`)

The SABCA mobile application targets iOS and Android from a shared TypeScript/React Native codebase built on **Expo SDK `^54.0.33`**, **React `19.1.0`**, **React Native `0.81.5`**, and **Expo Router `^6.0.23`**.

## Core Runtime Stack

| Package | Version | Purpose |
| :--- | :--- | :--- |
| `expo` | `^54.0.33` | Native runtime, prebuild generation, SecureStore, LocalAuthentication, Print, FileSystem |
| `expo-router` | `^6.0.23` | File-system routing under `sabca-app/app/` |
| `react` / `react-native` | `19.1.0` / `0.81.5` | Cross-platform UI runtime with `babel-plugin-react-compiler` |
| `@supabase/supabase-js` | `^2.93.3` | Auth, PostgREST queries, RPCs, Realtime channels, and Storage uploads |
| `@tanstack/react-query` | `^5.90.21` | Paginated server-state caching and infinite scroll queries |
| `i18next` / `react-i18next` | `^25.8.13` / `^16.5.4` | Bilingual English & Telugu UI translations (`locales/en.json`, `locales/te.json`) |
| `typescript` | `^5.3.0` | Static type checking (`npx tsc --noEmit`) |

## Provider Tree & Auth Navigation Guard

`sabca-app/app/_layout.tsx` composes global context providers around `<InitialLayout />`, which enforces session and profile completeness routing before rendering stack screens:

```tsx
SafeAreaProvider
 └─ QueryClientProvider
     └─ ThemeProvider
         └─ LanguageProvider
             └─ AuthProvider
                 └─ ModerationProvider
                     └─ InitialLayout (<Stack screenOptions={{ headerShown: false }} />)
```

## Directory Structure & Main Tabs

The primary bottom-tab navigator (`sabca-app/app/(tabs)/_layout.tsx`) exposes four primary member tabs:

- `index` — Home dashboard, Membership ID Card (`formatIdCardFields`), quick status actions, profile settings, and account danger zone.
- `sabca` — State Committee, Division Leaders, district list, and filterable Association Directory.
- `events` — Infinite-scrolled Events, News announcements, and live Realtime Polls.
- `services` — Member self-service portal for Grievances, Government Orders (`go-list`), Membership Renewal, Documents, and Transaction Receipts.

## Design Tokens & Bilingual i18n

- **Theme Palette (`constants/Colors.ts`)**: Dual light/dark color system anchored by Primary Red (`#E53935`), Brand Purple (`#8E44AD`), and Brand Blue (`#3B82F6`), plus dedicated status colors for grievance lifecycle pills (`submitted`, `underReview`, `inProgress`, `resolved`, `rejected`, `escalated`).
- **Localization (`lib/i18n.ts`)**: Initializes `i18next` with English (`en`) as default/fallback language and Telugu (`te`), wrapped with `LanguageProvider` (`ctx/LanguageContext.tsx`).
