## Store Upload Rules

- **Monotonic Increments**: Both Apple App Store Connect (`CFBundleVersion` / `expo.ios.buildNumber`) and Google Play Console (`versionCode` / `expo.android.versionCode`) reject duplicate build integers for the same or newer trains.
- **EAS Remote Version Source**: `sabca-app/eas.json` sets `"appVersionSource": "remote"` and `build.production.autoIncrement: true`, using Node `22.x`, `corepack: true`, and `pnpm: "10.34.9"`.
- **Native Parity**: When bumping locally for direct Xcode Archive or Gradle bundle builds, update `app.json`, `package.json`, `ios/SABCA/Info.plist`, `ios/SABCA.xcodeproj/project.pbxproj` (Debug + Release targets), and `android/app/build.gradle` in lockstep.
