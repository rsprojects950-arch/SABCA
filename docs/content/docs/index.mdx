# SABCA Monorepo Architecture

The **SABCA** repository unites two production user-facing surfaces alongside this interactive engineering documentation portal on the `master` branch:

- **`sabca-app/`** — Cross-platform iOS & Android association application built with **Expo SDK 54**, **React Native 0.81.5**, and **Expo Router v6**, backed by **Supabase** (Auth, PostgreSQL with Row-Level Security, Realtime, Storage, and Deno Edge Functions).
- **`website/`** — Unified static HTML/CSS/JS public portal serving the association showcase, official **Privacy Policy**, **Terms of Service**, **Account Deletion** self-service request flow, and App Store review visual references.
- **`docs/`** — This **Fumadocs + Next.js** developer knowledge base featuring theme-aware Mermaid diagrams, interactive Three.js 3D visualizers, and searchable SQL migration tooling.
